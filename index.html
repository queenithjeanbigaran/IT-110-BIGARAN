Tag reference

Tag Purpose
<html> Root element wrapping the whole page
<head> Holds page info that isn't shown directly
<meta> Sets page metadata, like character encoding
<title> Sets the browser tab title
<body> Contains everything visible on the page
<div> A generic container for grouping content
<header> Introductory content at the top of the page
<h1> Main heading
<h2> Section heading
<p> Paragraph text
<strong> Marks text as important, shown in bold
<img> Embeds an image
<ul> An unordered (bulleted) list
<li> A single item in a list
<a> A hyperlink to another page
<table> Creates a data table
<tr> A row within a table
<th> A header cell in a table
<td> A regular data cell in a table
<footer> Closing content at the bottom of the page
